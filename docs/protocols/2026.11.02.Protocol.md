# Revert from MontiGem-specific UMLP DSL to CD4A/CD4C.

**Problem:**

Models with `umlp` extensions using `umlp` keyword instead of `cd` extensions
and `classdiagram` keyword respectively are not properly processed by the
tooling handling class diagrams.

**Example:**

```java
// UMLP model in MyDomain.umlp
umlp MyDomain { }
```

**Alternative:**

Switch back to:
```java
// CD4Code model in MyDomain.cd
classdiagram MyDomain { }
```

**Verdict**
---

**Alternative** approved on 02.11.2026

# Replace generated XBuilder inheriting X

**Problem:**

Generated infrastructure includes builder and domain classes. Practical usage of
builders is either limited or complicated.
To consider:
- Domain object creation may require validation on the server, i.e.
  non-persisted objects may be transferred to server for validation and get
  either rejected or persisted. 
- Builder method chaining

**Example:**

```java
// UMLP model in MyDomain.umlp
umlp MyDomain {
  class Car {
    String brand;
  }
}
```

Generated classes with partial signature:
```java
// gen java
class Car {
  public String getBrand() { /*...*/ }

  public boolean isBuildFinished() { /*...*/ }
}
```
```java
// gen java
class CarBuilder extends Car {
  public boolean isBuildFinished() { /*...*/ }
}
```

Hand-written GUI model describing a form for
- creating a new `Car`
- updating an existing `Car`
```java
// hw GUI model
component CarForm(
  Car c = MyDomainManager.carBuilder() // builder by default
) {
  @GemTextInput(entry = c.brand);
  // show create button if car doesn't exist yet 
  @guard(!c.isBuildFinished()) {
    @GemButton(leftClick = () -> c.build());
  }
}
```

**Alternative 1:**

Generate a model with an extra variable
```java
// hw GUI model
component CarForm(
  CarBuilder cb = MyDomainManager.carBuilder(),
  Car c = cb
) {
  @GemTextInput(entry = c.brand);
  @guard(!cb.isBuildFinished()) {
    @GemButton(leftClick = () -> cb.build());
  }
}
```
- App-developer must be aware of this pattern.
- The variables `c` and `cb` must hold the same value, if `CarForm` is
  initialized with a builder (used of object creation)

**Alternative 2:**

Generate an additional proxy with an API delegating to builder or domain object:
```java
// gen java
class CarWrapper {
  protected Optional<Car> c;
  protected Optional<CarBuilder> cb;

  public String getBrand() { /* cb.getBrand() or c.getBrand() */ }

  public boolean carSaved() { /* cb.isBuildFinished() or true */ }
  public boolean save() { /* cb.build() or nothing*/ }
  public boolean isValid() { /* validation */ }
}
```
Use proxy:
```java
// hw GUI model
component CarForm(
  CarWrapper c = CarWrapper(MyDomainManager.carBuilder())
) {
  @GemTextInput(entry = c.brand);
  @guard(!c.isBuildFinished()) {
    @GemButton(leftClick = () -> c.build());
  }
}
```
- Complicated structure
- Implementation undecided

**Alternative 3:**

Generate an additional flag for `Car` representing object state and eliminate
`CarBuilder`:
```java
// gen java
class Car {
  protected boolean persisted = false;
  public String getBrand() { /*...*/ }

  public boolean isPersisted() { return persisted; }
  public boolean persist() { /*...*/ }
}
```
```java
// hw GUI model
component CarForm(
  Car c = MyDomainManager.car()
) {
  @GemTextInput(entry = c.brand);
  @guard(!c.isPersisted()) {
    @GemButton(leftClick = () -> c.persist());
  }
}
```
- Important: clear and intuitive flag name

**Verdict**
---

**Alternative 3** approved on 02.11.2026
