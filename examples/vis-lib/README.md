# Vis-Lib - the MontiGem component demonstrator

Shows every GUI component of the MontiGem runtime library (`umlp-rte/frontend`) in a
running application that was itself generated by MontiGem. Each example page shows a
component at work, the GUI model it was generated from, the handwritten Java logic and
the styling - and explains the component with the text of the library documentation.

## Start the app

Start the backend:
```
gradle :examples:vis-lib:backend:runServer
```
Start the frontend:
```
gradle :examples:vis-lib:frontend:runApp
```
The app is accessible at http://localhost:4200

## What is where

| Path | Content |
|---|---|
| `models/Domain.umlp` | The class diagram of the demo domain (persons, friends, stocks, chat messages, Fischertechnik states, chart commands). |
| `frontend/src/main/gui/common` | The demonstrator frame: `LandingPage`, `AboutMontiGem`, the category overview `OtherOverview`, and `ExamplePage` with its `CodeViewer`. Plus the notes components: `DemoBox` (the dashed "Demonstrator" frame), `InfoCard`, `DemoInstructions`, `ParameterList`, `ExampleNotes`, `EntryCard`, `ComponentCard`. |
| `frontend/src/main/gui/example_*` | One `<Name>Example.gui` page per library component - the plain usage of the component, wrapped in `@ExamplePage(...)`. |
| `frontend/src/main/gui/example_*/<Name>Notes.gui` | The demonstrator notes of that page: `@ExampleNotes(title, docComponents, about, tryIt)`. Kept out of the example page on purpose, see below. |
| `frontend/src/main/java/...` | Handwritten logic of the pages (TOP mechanism), e.g. the chart data computed from the persons in the database. |
| `frontend/src/main/java/common/ComponentDocs.java` | **Generated.** The doc comments of all library components (description, parameters), extracted from `umlp-rte/frontend/<lib>/src/main/gui/mc/fenix`. |
| `frontend/tools/ComponentDocsGenerator.java` | The generator behind `ComponentDocs.java`, run by the Gradle task `generateComponentDocs`. |
| `frontend/config/src/assets` | Images, audio, video and the CAD model used by the examples. |

## Where the explanations come from

The description and the parameter reference in the "Demonstrator" box of an example page
are the doc comments of the component models in the runtime library - the same comments
the online documentation (`docs/gendoc_components`, built by `comment2doc`) is generated
from. The Gradle task

```
gradle :examples:vis-lib:frontend:generateComponentDocs
```

extracts them into `frontend/src/main/java/common/ComponentDocs.java`. The task runs
automatically before every frontend build; the generated file is checked in so that the
sources compile without a build step as well. To change a text, change the doc comment
of the component in `umlp-rte` - never the generated file.

Only the "What you see" paragraphs and the "Try it yourself" steps are written by hand,
in the `<Name>Notes.gui` component next to every example page.

## Adding an example

1. Create `example_x/GemFooExample.gui`:
   ```
   page GemFooExample() {
     @ExamplePage(
       component = @GemFoo(...),
       basePath = "example_x",
       componentName = "GemFooExample",
       notes = @GemFooNotes()
     );
   }
   ```
   Keep it the plain usage of the component: `comment2doc` embeds the source of every
   `<Component>Example*` model into the online documentation of that component.
2. Create `example_x/GemFooNotes.gui` with `@ExampleNotes(title = "...",
   docComponents = ["GemFoo"], about = ["What you see.|...", ...], tryIt = ["...", ...])`.
   An `about` entry of the form `"<lead>|<body>"` renders the lead in bold.
   The notes file must not be named `...Example...` - `comment2doc` would treat it as a
   documentation example.
3. Add a `ComponentCard` to the category overview page and a `GemNavItem` to
   `navigation/Navigation.gui`.
4. Optional: add a `Screenshot` entry to `src/test/java/doc/ScreenshotGen.java` so the
   documentation gets a picture.

## Screenshots for the documentation

```
gradle :examples:vis-lib:frontend:screenshot
```

takes a screenshot of the demonstrated component (the `.examplePreview` column of each
example page, without notes and toolbar) into `docs/gendoc_img`.
